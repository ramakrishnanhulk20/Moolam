Dreamloom is a made-up AI image company, built as the demo of an outside platform giving every picture it draws a Moolam passport through the built @moolam/platform package; its viem must stay on the kit's exact version.
Run it with `npm run dev --workspace packages/dreamloom` from the repo root (port 3300, the kit is built first); on a host, `npm start` serves the build on the port in PORT.
