Repeat the comparison
From the repo root in Git Bash with Foundry on the PATH. It builds the tagged source in a temporary folder and prints
"equal" or "DIFFERENT" with the sha256 of the raw bytes for each contract:
H=$(mktemp -d); git archive deployed-source-2026-09-26 packages/contracts/src | tar -x -C $H; cp -r packages/contracts/lib packages/contracts/foundry.toml packages/contracts/remappings.txt $H/packages/contracts/; for c in MoolamRegistry VerifierPolicy MoolamReceiver MoolamConsent SimulationReceiver; do for k in deployedBytecode bytecode; do a=$(cd $H/packages/contracts && forge inspect $c $k | sed 's/^0x//' | xxd -r -p | sha256sum); b=$(cd packages/contracts && forge inspect $c $k | sed 's/^0x//' | xxd -r -p | sha256sum); [ "$a" = "$b" ] && echo "equal $c $k ${b%% *}" || echo "DIFFERENT $c $k"; done; done; rm -rf $H
