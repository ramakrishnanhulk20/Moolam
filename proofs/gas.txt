The four scenarios the work order names, measured with gasleft around the call in
test_gasOfTheMainActions, so each figure is the gas the call itself burns and does not include
the 21,000 gas every transaction pays before it starts or the cost of its calldata.

| action                                   | gas     |
|------------------------------------------+---------|
| first statement for a passport           | 117,114 |
| a later statement, no constraint text    |  90,813 |
| a statement with 256 bytes of text       | 326,266 |
| consentAt with 2 entries in the history  |  30,654 |
| consentAt with 16 entries                |  16,785 |
| consentAt with 256 entries               |  35,517 |

The first statement costs more because it starts the passport's history: the list length and the
first entry are both fresh storage. Every later statement writes one fresh slot and updates the
length, which is why it settles around 90,000 whatever the values are. A statement with 256 bytes of
constraint text costs what it costs because the text itself is nine more storage slots.

consentAt is a binary search, so the history length barely moves it: 16 entries reads cheaper than
2 only because the entry it lands on sits in a slot already touched. Reads cost a user nothing
anyway, they are eth_call.

What this means for a creator, in plain English. Monad mainnet was quoting 102 gwei when this was
measured (base fee 100, priority 2). A creator's first statement is about 140,000 gas all in,
which is about 0.014 MON. Every statement after that is about 114,000 gas, about 0.012 MON. Adding
a full length 256 byte note about their conditions takes it to about 0.036 MON. Reading what a
passport allows, on any date, is free.
